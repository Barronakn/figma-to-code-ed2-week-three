# 🏡 Tokena Finace App

## 📌 Description  
Tokena Finance App est une application moderne et intuitive conçue pour vous aider à gérer efficacement vos finances. Que vous soyez un particulier souhaitant suivre vos dépenses ou une entreprise cherchant à optimiser sa trésorerie, Tokena vous offre des outils puissants pour prendre le contrôle de votre argent et avoir l'évolution de bitcoin.

## 🚀 Technologies utilisées  
- **Frontend** : React.js, TailwindCSS  
- **APIs** : api.coingecko.com  

## 🎨 Fonctionnalités principales  
- **Navigation fluide et responsive**  
- **Évolution des bitcoin en temps réels**  
- **Système de recherche avancée**  
- **Expérience utilisateur optimisée pour le haut de gamme**  
- **Dashboard modernes pour un rendu visuel attractif**  

## 🔧 Installation et exécution en local  
1. **Cloner le projet**  
   ```bash
   git clone https://github.com/Barronakn/figma-to-code-ed2-week-three.git
   cd figma-to-code-ed2-week-three
   ```

2. **Installation des dépendances**  
   ```bash
   npm install  # Pour React et TailwindCSS
  ```

3. **Lancer le serveur frontend**  
   ```bash
   npm start
   ```
